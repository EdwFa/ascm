# Руководство для врачей-разметчиков

Файл `results/annotation/seed_passages.csv` содержит отрывки из рекомендаций (`passage`) и их уровни доказательности (`evidence`).
Отрывки выбраны случайно до запуска любого чанкера, чтобы вопросы не подгонялись под разбиение.

Для каждой строки (или для части строк) напишите вопрос так, как его задал бы клиницист, который не видит отрывок:

| Колонка | Что внести |
|---|---|
| `type` | `factual`, `evidence`, `conditional`, `table_list`, `multistep` |
| `question` | Формулировка вопроса, не копирующая отрывок дословно |
| `answerable` | `yes` или `no` (около 10% вопросов не должны иметь ответа в корпусе) |
| `answer` | Эталонный ответ |
| `notes` | Если для ответа нужен ещё один отрывок (`multistep`), укажите его `id` |

Правила:
1. Вопрос типа `evidence` спрашивает об уровне убедительности или достоверности и должен требовать строки из `evidence`.
2. Для `answerable=no` придумайте вопрос по теме документа, ответа на который в нём нет; `start`/`end` оставьте пустыми.
3. Разметка по символам берётся из колонок `start`/`end` (смещения в `data/processed/<doc>.txt`); сужать диапазон до минимального отрывка нужно вручную.
4. Второй врач независимо размечает 25% вопросов; целевой κ ≥ 0,7.

Цель: 240 вопросов, примерно 30 на документ. Доли типов: factual 30%, evidence 30%, conditional 20%, table_list 10%, multistep 10%.
